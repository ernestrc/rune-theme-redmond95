# Redmond 95 theme for Rune

A copyable [Rune theme package](https://docs.rune.build/docs/learn/themes#share-your-theme)
containing the `redmond95` palette.

## Install

In the Rune console, run:

```text
pkg install github.com/ernestrc/rune-theme-redmond95
```

Reload Rune, then:

```text
guitheme redmond95
```

To use it at startup, set `gui.default_theme: redmond95` in your own
`config.yaml`. Installing the package does not change your default theme.
